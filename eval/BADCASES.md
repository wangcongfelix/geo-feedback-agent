# GeoFeedback Agent Badcases

> 当前文件用于记录 Golden Set 或人工测试中发现的失败案例。
> 现阶段仅建立记录模板，不预填任何未发生的 Badcase。

## 记录原则

- 不编造 Badcase。
- 不记录真实用户隐私信息。
- 不把合理多解直接判定为模型错误，需要先说明人工标准答案和歧义原因。
- Prompt 修改建议必须基于实际失败样例。

## 已记录 Badcase

### badcase_v1_001

- case_id: gs_v1_005
- prompt_version: v1
- provider: DeepSeek
- model: deepseek-v4-flash
- 原始反馈: 导入shp后图层能显示，但属性表里的中文全是乱码。
- AI预测模块: B端平台配置与数据处理
- 人工期望模块: 离线地图、文件与数据管理
- AI预测问题类型: Bug
- 人工期望问题类型: Bug
- 错误类型: 模块分类错误
- Badcase类型: 分类边界歧义
- 当前状态: open
- 初步原因: 反馈同时包含“B端GIS平台”语境和“shp文件导入/属性表乱码”现象，B端场景与文件导入模块边界重叠。该案例不能描述为绝对错误根因，应作为分类边界歧义处理。
- 建议的Prompt V2规则: 当反馈核心现象是文件导入、文件编码、属性表、离线包或数据文件处理异常时，即使发生在B端GIS平台，也优先判断为“离线地图、文件与数据管理”；仅当反馈核心是后台配置、权限、服务发布、数据处理流程或平台参数时，才优先判断为“B端平台配置与数据处理”。
- 备注: 需要人工复核完整输出中是否正确保留了“文件编码或操作问题”的不确定性。

### badcase_v1_002

- case_id: gs_v1_012
- prompt_version: v1
- provider: DeepSeek
- model: deepseek-v4-flash
- 原始反馈: 定位又不准了。
- AI预测模块: 其他或无法判断
- 人工期望模块: 定位与轨迹
- AI预测问题类型: 信息不足，暂时无法判断
- 人工期望问题类型: 信息不足，暂时无法判断
- 错误类型: 模块分类错误
- Badcase类型: 模块判断与问题类型判断未充分独立
- 当前状态: open
- 初步原因: 反馈信息不足以判断问题类型，但“定位”关键词已经足以判断产品模块为“定位与轨迹”。模型将问题类型的信息不足扩散到了模块判断。
- 建议的Prompt V2规则: 模块判断与问题类型判断应相互独立；当反馈中明确出现定位、轨迹、GPS、方向箭头等模块线索时，即使问题类型应为“信息不足，暂时无法判断”，产品模块仍应选择“定位与轨迹”，而不是“其他或无法判断”。
- 备注: 该案例的问题类型预测正确，Badcase仅针对模块分类。
